# Задача закончилась, а ты этого не заметил

macOS-уведомление приходит, когда Claude Code закончил работу, задал вопрос или показал план.
В подзаголовке — название сессии, так что из десяти окон видно, какое именно освободилось.
Клик по уведомлению переключает на нужную вкладку iTerm2.

Это форк [claude-notifications-go](https://github.com/777genius/claude-notifications-go) (GPL-3.0)
с четырьмя правками: подзаголовок = имя сессии, без хвоста со счётчиками, гейт на фоновые задачи,
русские заголовки по умолчанию.

## Что это

Плагин Claude Code: пять хуков (Stop, SubagentStop, PreToolUse, Notification, TeammateIdle)
дёргают Go-бинарь, который шлёт нативное уведомление macOS.

Отличия от апстрима:

- **Подзаголовок — реальное имя сессии.** Апстрим пишет `ветка · папка`. Форк читает
  `custom-title.json` Claude Code и показывает то имя, которое видно в самом Claude Code.
- **Без хвоста со счётчиками.** Апстрим дописывает в тело `📝 1 new ▶ 2 cmds ⏱ 41s`. Форк оставляет
  только текст резюме.
- **Гейт на фоновые задачи.** «Задача выполнена» не приходит, пока в сессии крутятся фоновые агенты
  или воркфлоу.
- **Русские заголовки и звук выключен** — в дефолтном конфиге.

## Установка

```bash
claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
claude plugin install jadlis-notifications@jadlis
```

Отдельно ставить обычно не нужно: плагин приезжает как зависимость `jadlis-claudecode`.

Патченый бинарь `darwin/arm64` лежит прямо в репозитории, так что после установки плагин работает
сразу. Если бинарь потеряется или разойдётся по версии с `plugin.json`, `bin/hook-wrapper.sh`
скачает его из релиза `v<версия>` этого форка — к апстриму он не ходит.

## Что видно

| Событие | Заголовок |
|---|---|
| Claude закончил | ✅ Задача выполнена |
| Ревью закончено | 🔍 Ревью завершено |
| Задан вопрос | ❓ Есть вопрос |
| План готов | 📋 План готов |

Подзаголовок — имя сессии. Звук выключен, метка сессии в заголовке выключена, клик по уведомлению
поднимает iTerm2 и нужную вкладку.

Свои значения кладутся в `~/.claude/claude-notifications-go/config.json` — путь захардкожен в
апстримном коде и в форке намеренно не менялся, так что уже существующий конфиг подхватывается
как есть. Этот файл главнее того, что лежит в `config/config.json` плагина. Кэши и указатели
плагина при этом переехали в свой неймспейс (`~/.cache/jadlis-notifications/`,
`~/.claude/jadlis-notifications/`), так что апстримный плагин рядом ничему не мешает.

## Гейт фоновых задач

`bin/stop-gate.sh` стоит перед Stop-хуком. Он считает по транскрипту сессии незавершённые фоновые
агенты и воркфлоу (`bin/pending-bg-tasks.py`); пока их больше нуля — уведомление глушится, потом
событие уходит в `bin/hook-wrapper.sh` без изменений. Любая ошибка счётчика = ноль, то есть
уведомление проходит. Запуск старше 6 часов без уведомления о завершении считается мёртвым.

Лог решений — `${TMPDIR}/jadlis-notifications-stop-gate.log`, обрезается на 256 КБ.

## Клик по уведомлению в iTerm2

Точное попадание во вкладку требует iTerm2 Python API. Один раз руками:

1. iTerm2 → Settings → General → Magic → **Enable Python API**, перезапустить iTerm2.
2. Venv ставит `bin/install.sh` при первой установке; вручную —
   `python3 -m venv ~/.claude/claude-notifications-go/iterm2-venv` и
   `~/.claude/claude-notifications-go/iterm2-venv/bin/pip install iterm2`.

Путь venv тоже захардкожен в апстримном коде и в форке не менялся. Без Python API клик просто
поднимает iTerm2 без выбора вкладки.
